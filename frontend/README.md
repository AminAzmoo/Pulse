# Pulse Frontend

Pulse is a Nuxt 3 frontend that provides an operational console for network visibility.

## Tech Stack

- Nuxt 3 (Vue 3 + Composition API)
- TypeScript (via Nuxt)

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Project Structure

```
assets/         # Global styles
components/     # Shared UI components
layouts/        # Application shell layouts
pages/          # Route-based views
```
